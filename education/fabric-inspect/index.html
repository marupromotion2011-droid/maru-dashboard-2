원단 검사

원단 롤 위에 있는 흠을 보고 점수를 매기는 공개 방식. 쉬운 말로 4점법. 표준 이름은 ASTM D5430. 합격 문턱은 바이어 계약.

결함 점수 4점법 합격=계약

4점법 흐름: 원단 롤 → 검단기에서 결함 찾기 → 결함마다 점수(1–4점) → 100 yd²로 환산해 판정. 환산 식은 아래 표. 검단기 실물은 아래 사진.

왜 배우나 왜

재단 전에 롤을 눈으로
VISUAL GATE

조명 밖에서 표면 흠을 찾고 점수를 매긴다. 재단 넣기 전 검문.

랩 테스트와는 다른 검사
LAB GATE

색 빠짐·수축·무게(GSM)은 실험실. 이 페이지는 눈으로 보는 검사. 둘 다 필요.

합격 문턱=계약
CONTRACT

공개 업계 예(~40, ~20-28) 있으나 공장 합격점이 아니다. 바이어 스펙.

공장 합격점·검사 속도·보유 검사기는 이 페이지로 정하지 않는다. 작지·QC를 본다.

구멍(hole) 공개 자료에 두 후보. A ≤1 in=2 / >1 in=4. B 크기 무관 4. 표에 두 후보를 적고 바이어 스펙 확인.

퀴즈 확인

1. ASTM D5430 4점법은?

시각 결함 1-4점 채점 후 100 yd² 환산. 랩과 별개.

2. ≤3 in 결함 점수는?

≤3 in = 1점, 3–6 = 2, 6–9 = 3, >9 = 4.

3. 구멍 채점은?

두 후보 표시 후 계약 확정.

4. 기준 환산 공식은?

Points/100 yd². 환산은 HTML 표 공식.

5. ~40, ~20-28 /100 yd²는?

공장 합격점이 아니다.

6. 시각 4점과 랩은?

표면 vs 공학. 둘 다 게이트.

7. 1야드당 캡은?

야드당·단 결함 모두 최대 4.

8. 스펙 칸 vs 검사 칸?

../원단스펙/index.html

9. 현장말 나오시 = ?

기스=흠집, 간지=견본, 나오시=수선/수정.

10. 재단 전 빠지면 안 될 단계?

채점 → 환산 → 계약 판정 후 투입.
