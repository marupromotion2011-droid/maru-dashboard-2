전체공정

티 한 벌이 지나가는 길을 한 줄로 본다. 재료 → 실 → 원단 → 색 → 손질 → 자르기 → 바느질 → 보내기. 자세한 건 각 페이지에서 본다.

한 줄 흐름 각 칸 링크 작지·바이어

전체 흐름 그림이다. 자세한 건 각 페이지를 연다. 선염은 실을 먼저 염색한 뒤 편직한다.

이 페이지 숫자로 공장 규격을 정하지 않는다. 작지·바이어 스펙을 본다.

한 줄 흐름 흐름

본선(후염): 섬유 → 방적 → 편직 → 염색 → 후가공 → 재단 → 봉제 → 출고.

선염 분기: 섬유 → 방적 → 사염(선염) → 편직 → (필요 시 후가공) → 재단 → 봉제 → 출고. 염색 페이지의 선염·후염과 같다.

퀴즈 확인

1. 한 줄 흐름의 첫 칸은?

섬유 → 방적 → … → 출고.

2. 후염 본선에서 방적 다음은?

후염 본선은 실→원단→염색. 선염 분기는 방적 다음 사염(선염)이 먼저다.

3. 염색 다음은 흔히?

염색 후 텐터 등 후가공으로 안정화.

4. 재단 직후 본선은?

재단 부품 → 봉제.

5. 봉제기기 칸은?

관련 칸. 기종·실 콘수.

6. 원단검사 단계는 흐름에서?

관련 칸. 롤 시각 4점.

7. 생산관리에서 흐름을 보는 이유는?

한 줄로 앞뒤 공정을 보는 용도.

8. 이 페이지로 팀 조직도를 정하면?

역할 개념만. 팀 배치는 현장·작지.
